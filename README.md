Moonli Clone

A fully interactive **frontend-only clone** of the Moonli website, built using HTML, CSS, JavaScript, and the powerful **GSAP animation library**. 
This project replicates the original site's look and feel while emphasizing animation, transitions, and user interaction.

---

## Features

- Responsive and interactive design
- Smooth animations with [GSAP (GreenSock Animation Platform)]
- Modern HTML/CSS layout
- Scroll and hover-triggered effects
- Modular and clean code structure

---

## Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **GSAP (GreenSock Animation Platform)**
